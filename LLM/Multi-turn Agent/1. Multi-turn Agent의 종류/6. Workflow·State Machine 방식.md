# 6. Workflow·State Machine 방식
업무 절차를 명시적인 상태와 전이 규칙으로 구현합니다.

```
요청 접수
   ↓
요구사항 확인
   ↓
검색 조건 확정
   ↓
논문 검색
   ↓
검색 결과 검증
   ↓
논문 분류
   ↓
결과 보고서 생성
```

예를 들어 상태를 다음과 같이 정의할 수 있습니다.

```python
from enum import StrEnum


class AgentStep(StrEnum):
    REQUIREMENT_COLLECTION = "requirement_collection"
    SEARCH = "search"
    VALIDATION = "validation"
    CLASSIFICATION = "classification"
    REPORT_GENERATION = "report_generation"
    COMPLETED = "completed"
```

각 상태에서 실행 가능한 행동을 제한합니다.

```python
def get_next_step(state: AgentStep, result: dict) -> AgentStep:
    if state == AgentStep.REQUIREMENT_COLLECTION:
        return AgentStep.SEARCH

    if state == AgentStep.SEARCH and result["count"] > 0:
        return AgentStep.VALIDATION

    if state == AgentStep.VALIDATION and result["is_valid"]:
        return AgentStep.CLASSIFICATION

    return state
```

### 장점
* 업무 흐름이 명확하고 통제 가능함
* 오류 처리와 재시도가 쉬움
* 단계별 로그 및 감사 기록을 남길 수 있음
* 기업용 업무 자동화에 적합함

### 단점
* 유연한 대화를 구현하기 어려울 수 있음
* 상태와 전이 규칙 설계가 필요함
* 복잡한 워크플로는 유지보수 부담이 커짐

LLM에게 전체 흐름을 자유롭게 맡기는 것보다, 중요한 업무에서는 State Machine이나 그래프 기반 Workflow로 행동 범위를 제한하는 것이 안전합니다.

상태 전이는 표로 정의하면 구현과 검토가 쉬워집니다.

| 현재 상태 | 조건 | 다음 상태 |
| --- | --- | --- |
| REQUIREMENT_COLLECTION | 필수 조건이 모두 수집됨 | SEARCH |
| SEARCH | 검색 결과가 1건 이상 | VALIDATION |
| SEARCH | 검색 결과가 없음 | REQUIREMENT_COLLECTION |
| VALIDATION | 결과가 유효함 | CLASSIFICATION |
| VALIDATION | 결과가 유효하지 않음 | SEARCH |
| CLASSIFICATION | 분류 완료 | REPORT_GENERATION |
| REPORT_GENERATION | 보고서 생성 완료 | COMPLETED |

오류 상태도 별도로 설계해야 합니다.

```python
class AgentStep(StrEnum):
    REQUIREMENT_COLLECTION = "requirement_collection"
    SEARCH = "search"
    VALIDATION = "validation"
    CLASSIFICATION = "classification"
    REPORT_GENERATION = "report_generation"
    WAITING_FOR_USER = "waiting_for_user"
    FAILED = "failed"
    COMPLETED = "completed"
```

### 적합한 경우
* 규제, 승인, 결제처럼 절차 통제가 중요한 업무
* 실패 시 재시도 또는 롤백이 필요한 업무
* 여러 팀이나 시스템이 관여하는 업무 자동화
* 감사 로그와 상태 추적이 필요한 기업용 Agent

Workflow 방식에서는 LLM이 상태 전이를 직접 결정하기보다, 상태 전이 후보를 제안하고 애플리케이션이 검증하는 구조가 더 안전합니다.
