# ref와 브랜치 심화

브랜치는 특별한 저장 공간이 아니라 커밋을 가리키는 이름 있는 참조(ref)이다.

## 1. ref

ref는 특정 객체 해시를 가리키는 이름이다.

대표적인 ref:

* `refs/heads/main`: 로컬 브랜치
* `refs/remotes/origin/main`: 원격 추적 브랜치
* `refs/tags/v1.0.0`: 태그

확인:

```bash
git show-ref
```

## 2. HEAD

`HEAD`는 현재 위치를 나타낸다.

일반적인 상태:

```text
HEAD -> refs/heads/main -> 커밋
```

detached HEAD 상태:

```text
HEAD -> 특정 커밋
```

detached HEAD에서는 커밋을 만들 수 있지만 브랜치 이름이 없으면 나중에 찾기 어려워질 수 있다.

복구:

```bash
git switch -c rescue-branch
```

## 3. 로컬 브랜치와 원격 추적 브랜치

로컬 브랜치:

```text
main
```

원격 추적 브랜치:

```text
origin/main
```

`origin/main`은 원격 저장소의 `main`을 마지막으로 가져왔을 때의 로컬 기록이다. 실제 원격 서버를 실시간으로 보여 주는 것이 아니다.

최신화:

```bash
git fetch origin
```

## 4. upstream

upstream은 로컬 브랜치가 기본으로 push/pull할 원격 브랜치이다.

확인:

```bash
git branch -vv
```

설정:

```bash
git push -u origin feature-login
```

또는:

```bash
git branch --set-upstream-to=origin/feature-login feature-login
```

## 5. 브랜치가 앞서거나 뒤처진 상태

`git status`에서 다음 표현을 볼 수 있다.

* ahead: 로컬에만 있는 커밋이 있음
* behind: 원격 추적 브랜치에만 있는 커밋이 있음
* diverged: 양쪽에 서로 다른 커밋이 있음

상황 확인:

```bash
git log --oneline --graph --decorate --all
git branch -vv
```

## 6. 태그의 종류

lightweight tag:

```bash
git tag v1.0.0
```

annotated tag:

```bash
git tag -a v1.0.0 -m "Release v1.0.0"
```

릴리스에는 작성자, 날짜, 메시지를 포함하는 annotated tag를 권장한다.
