# Git 핵심 개념

## 1. Git이 하는 일

Git은 프로젝트 파일의 변경 이력을 커밋 단위로 저장하는 분산 버전 관리 시스템(DVCS)이다.

Git을 사용하면 다음 작업이 가능하다.

* 파일 변경 이력 확인
* 이전 버전으로 되돌리기
* 여러 기능을 브랜치로 나누어 개발
* 원격 저장소를 통해 협업
* 충돌 발생 시 변경 내용을 비교하고 선택

## 2. Git의 주요 공간

Git 작업은 네 가지 공간을 오가며 진행된다.

```text
워킹 디렉토리 --git add--> 스테이징 영역 --git commit--> 로컬 저장소 --git push--> 원격 저장소
```

* 워킹 디렉토리: 실제 파일을 수정하는 작업 공간
* 스테이징 영역: 다음 커밋에 포함할 변경을 준비하는 공간
* 로컬 저장소: 내 컴퓨터에 저장된 Git 이력
* 원격 저장소: GitHub 같은 서버에 있는 공유 저장소

## 3. 기본 용어

* Repository: Git이 관리하는 저장소
* Commit: 변경 사항을 저장소에 기록한 단위
* Branch: 독립적인 작업 흐름
* Merge: 다른 브랜치의 변경을 현재 브랜치에 합치는 작업
* Remote: 원격 저장소 연결 이름
* Origin: 보통 기본 원격 저장소에 붙이는 이름
* HEAD: 현재 체크아웃한 브랜치 또는 커밋을 가리키는 포인터

## 4. 커밋과 해시

Git의 커밋은 특정 시점의 프로젝트 스냅샷이다. 각 커밋에는 고유한 해시가 붙는다.

```bash
git log --oneline
```

예시:

```text
a1b2c3d Add login page
```

해시는 특정 커밋을 가리키는 식별자이며, 비교, 되돌리기, 특정 커밋 확인에 사용된다.

## 5. HEAD

`HEAD`는 현재 내가 보고 있는 브랜치나 커밋을 가리킨다.

* 보통 현재 브랜치의 최신 커밋을 가리킴
* 브랜치를 이동하면 `HEAD`도 함께 이동함
* 특정 커밋으로 직접 이동하면 detached HEAD 상태가 될 수 있음
