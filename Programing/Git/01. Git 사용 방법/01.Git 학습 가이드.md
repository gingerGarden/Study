## 가장 중요한 습관

Git 명령을 실행하기 전에는 먼저 현재 상태를 확인한다.

```bash
git status
```

변경 내용을 확인한다.

```bash
git diff
git diff --staged
```

내가 어느 브랜치에 있는지 확인한다.

```bash
git branch
```

## 기본 흐름

```text
워킹 디렉토리 --git add--> 스테이징 영역 --git commit--> 로컬 저장소 --git push--> 원격 저장소
원격 저장소 --git fetch/pull--> 로컬 저장소
```

## 자주 쓰는 명령 요약

| 목적 | 명령어 |
| --- | --- |
| 상태 확인 | `git status` |
| 변경 비교 | `git diff` |
| 스테이징 | `git add 파일명` |
| 전체 스테이징 | `git add .` |
| 커밋 | `git commit -m "메시지"` |
| 로그 확인 | `git log --oneline` |
| 브랜치 생성 및 이동 | `git switch -c 브랜치명` |
| 브랜치 이동 | `git switch 브랜치명` |
| 병합 | `git merge 브랜치명` |
| 원격 확인 | `git remote -v` |
| push | `git push origin 브랜치명` |
| pull | `git pull origin 브랜치명` |
| 스테이징 취소 | `git restore --staged 파일명` |
| 수정 취소 | `git restore 파일명` |
| 안전한 커밋 취소 | `git revert 커밋해시` |
| 임시 저장 | `git stash` |

## 주의할 명령

다음 명령은 이력을 바꾸거나 작업 내용을 잃을 수 있으므로 실행 전 반드시 `git status`와 `git log --oneline`을 확인한다.

```bash
git reset --hard
git push -f
git rebase
git commit --amend
```
