# 원격 저장소

## 1. 원격 저장소 연결

로컬 저장소에 원격 저장소를 연결한다.

```bash
git remote add origin https://github.com/username/repository.git
```

SSH 방식:

```bash
git remote add origin git@github.com:username/repository.git
```

연결 확인:

```bash
git remote -v
```

## 2. 원격 저장소 주소 변경

```bash
git remote set-url origin https://github.com/username/new-repository.git
```

## 3. 원격 저장소 이름 변경

```bash
git remote rename origin upstream
```

## 4. 원격 저장소 연결 삭제

```bash
git remote remove origin
```

## 5. 원격으로 push

```bash
git push origin main
```

처음 push하면서 현재 브랜치와 원격 브랜치를 연결:

```bash
git push -u origin main
```

이후에는 다음처럼 간단히 push할 수 있다.

```bash
git push
```

## 6. 원격 변경 가져오기

원격 변경을 가져오되 현재 브랜치에 합치지는 않음:

```bash
git fetch origin
```

원격 변경을 가져와 현재 브랜치에 병합:

```bash
git pull origin main
```

`git pull`은 보통 `git fetch`와 `git merge`를 이어서 실행하는 것과 비슷하다.

## 7. 원격 브랜치 가져와서 작업하기

원격 브랜치 목록 확인:

```bash
git branch -r
```

원격 브랜치를 로컬 브랜치로 가져와 이동:

```bash
git switch -c feature-login origin/feature-login
```

## 8. 원격 브랜치 삭제

```bash
git push origin --delete feature-login
```

로컬 브랜치도 삭제:

```bash
git branch -d feature-login
```
