# 설정과 저장소 시작

## 1. 최초 설정

Git을 처음 설치한 뒤에는 사용자 이름과 이메일을 설정한다. 이 정보는 커밋 작성자 정보로 기록된다.

```bash
git config --global user.name "사용자 이름"
git config --global user.email "sample@email.com"
```

기본 브랜치 이름을 `main`으로 설정한다.

```bash
git config --global init.defaultBranch main
```

기본 편집기를 설정한다.

```bash
git config --global core.editor "vim"
```

설정 확인:

```bash
git config --list
git config --global --list
```

특정 설정 확인:

```bash
git config user.name
git config user.email
```

## 2. 새 로컬 저장소 만들기

현재 디렉토리를 Git 저장소로 만든다.

```bash
git init
```

초기 파일을 추가하고 첫 커밋을 만든다.

```bash
git add .
git commit -m "Initial commit"
```

## 3. 원격 저장소 복제하기

이미 존재하는 원격 저장소를 내 컴퓨터로 가져올 때는 `clone`을 사용한다.

HTTPS 방식:

```bash
git clone https://github.com/username/repository.git
```

SSH 방식:

```bash
git clone git@github.com:username/repository.git
```

특정 폴더 이름으로 복제:

```bash
git clone https://github.com/username/repository.git my-project
```

## 4. 프로젝트 최상위 경로 확인

Git 저장소 안에서 현재 프로젝트의 최상위 경로를 확인한다.

```bash
git rev-parse --show-toplevel
```
