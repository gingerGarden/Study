# 브랜치와 병합

## 1. 브랜치 목록 확인

```bash
git branch
```

원격 브랜치까지 확인:

```bash
git branch -a
```

## 2. 브랜치 생성

브랜치만 생성:

```bash
git branch feature-login
```

브랜치를 만들고 바로 이동:

```bash
git switch -c feature-login
```

구버전 Git에서는 다음 명령도 많이 사용한다.

```bash
git checkout -b feature-login
```

## 3. 브랜치 이동

```bash
git switch main
```

구버전 방식:

```bash
git checkout main
```

## 4. 브랜치 이름 변경

현재 브랜치 이름 변경:

```bash
git branch -m new-branch-name
```

특정 브랜치 이름 변경:

```bash
git branch -m old-name new-name
```

## 5. 브랜치 삭제

병합된 브랜치 삭제:

```bash
git branch -d feature-login
```

병합 여부와 관계없이 강제 삭제:

```bash
git branch -D feature-login
```

주의: 강제 삭제는 해당 브랜치의 커밋을 잃을 수 있으므로 신중하게 사용한다.

## 6. 브랜치 병합

예를 들어 `feature-login` 브랜치 작업을 `main`에 합치려면 다음 순서로 진행한다.

```bash
git switch main
git pull origin main
git merge feature-login
```

병합 후 원격 저장소에 공유:

```bash
git push origin main
```

## 7. 충돌 해결

병합 중 충돌이 발생하면 Git은 충돌 파일에 표시를 남긴다.

```text
<<<<<<< HEAD
현재 브랜치의 내용
=======
병합하려는 브랜치의 내용
>>>>>>> feature-login
```

해결 순서:

1. `git status`로 충돌 파일을 확인한다.
2. 파일을 열어 남길 내용을 직접 정리한다.
3. 충돌 표시인 `<<<<<<<`, `=======`, `>>>>>>>`를 제거한다.
4. 해결한 파일을 스테이징한다.
5. 병합 커밋을 만든다.

```bash
git status
git add 충돌파일명
git commit
```

병합을 중단하고 이전 상태로 돌아가려면:

```bash
git merge --abort
```
