# 임시 저장과 제외 설정

## 1. stash

작업 중인 변경을 잠시 치워 두고 다른 브랜치로 이동해야 할 때 사용한다.

변경 임시 저장:

```bash
git stash
```

메시지와 함께 저장:

```bash
git stash push -m "WIP login form"
```

stash 목록 확인:

```bash
git stash list
```

가장 최근 stash 적용:

```bash
git stash apply
```

적용하면서 stash 목록에서 제거:

```bash
git stash pop
```

특정 stash 삭제:

```bash
git stash drop stash@{0}
```

## 2. .gitignore

Git에 올리지 않을 파일은 `.gitignore`에 작성한다.

예시:

```gitignore
node_modules/
.env
dist/
build/
*.log
__pycache__/
.DS_Store
```

이미 Git이 추적 중인 파일은 `.gitignore`에 추가해도 자동으로 제외되지 않는다. 추적만 중단하려면 다음 명령을 사용한다.

```bash
git rm --cached .env
```

디렉토리 전체 추적 중단:

```bash
git rm -r --cached node_modules/
```

## 3. 태그

태그는 특정 커밋에 버전 이름을 붙일 때 사용한다.

태그 생성:

```bash
git tag v1.0.0
```

메시지가 있는 태그 생성:

```bash
git tag -a v1.0.0 -m "Release v1.0.0"
```

태그 목록:

```bash
git tag
```

태그 push:

```bash
git push origin v1.0.0
```

모든 태그 push:

```bash
git push origin --tags
```
