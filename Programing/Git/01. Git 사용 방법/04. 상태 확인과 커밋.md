# 상태 확인과 커밋

## 1. 현재 상태 확인

```bash
git status
```

자주 확인해야 하는 정보:

* 현재 브랜치
* 수정된 파일
* 스테이징된 파일
* 추적되지 않는 파일
* 원격 브랜치보다 앞서거나 뒤처졌는지 여부

짧은 형식:

```bash
git status --short
```

## 2. 변경 내용 확인

아직 스테이징하지 않은 변경 확인:

```bash
git diff
```

스테이징된 변경 확인:

```bash
git diff --staged
```

특정 파일의 변경 확인:

```bash
git diff README.md
```

## 3. 스테이징하기

전체 변경 추가:

```bash
git add .
```

특정 파일만 추가:

```bash
git add README.md
```

특정 디렉토리 추가:

```bash
git add src/
```

파일 안의 일부 변경만 선택해서 추가:

```bash
git add -p
```

## 4. 커밋하기

```bash
git commit -m "Add login page"
```

커밋 메시지는 현재형 명령문처럼 작성하면 읽기 쉽다.

좋은 예:

```text
Add user login validation
Fix broken API error handling
Update Git study notes
```

나쁜 예:

```text
update
fix
작업함
```

## 5. 최근 커밋 수정하기

마지막 커밋 메시지만 수정:

```bash
git commit --amend -m "Update Git usage guide"
```

마지막 커밋에 파일 추가:

```bash
git add README.md
git commit --amend
```

주의: 이미 원격 저장소에 push한 커밋은 함부로 amend하지 않는다. 커밋 해시가 바뀐다.

## 6. 이력 조회

기본 로그:

```bash
git log
```

한 줄로 보기:

```bash
git log --oneline
```

브랜치 그래프까지 보기:

```bash
git log --oneline --graph --decorate --all
```

특정 파일 이력:

```bash
git log -- README.md
git log -p -- README.md
```

특정 커밋 내용:

```bash
git show <커밋 해시>
```
