## 실습 원칙

* 실제 프로젝트가 아닌 임시 폴더에서 실습한다.
* 위험한 명령을 실행하기 전에는 `git status`와 `git log --oneline`을 확인한다.
* 실습 중 막히면 명령을 추가로 실행하기 전에 현재 상태를 먼저 기록한다.
* 출력 예시는 환경마다 조금 다를 수 있다. 핵심은 메시지의 의미를 해석하는 것이다.

## 실습용 폴더 만들기

```bash
mkdir git-practice
cd git-practice
git init
```

예상 출력:

```text
Initialized empty Git repository in .../git-practice/.git/
```
