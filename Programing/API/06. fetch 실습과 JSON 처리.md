## 1. fetch 기본
`fetch`는 브라우저에서 HTTP 요청을 보낼 때 사용하는 JavaScript 내장 함수이다.

```javascript
fetch("https://api.example.com/users")
  .then((response) => response.json())
  .then((data) => {
    console.log(data);
  });
```

`fetch`는 Promise를 반환하므로 `then` 또는 `async/await`로 결과를 처리한다.

<br>

## 2. GET 요청
GET 요청은 데이터를 조회할 때 사용한다.

```javascript
async function getUsers() {
  const response = await fetch("https://api.example.com/users");
  const users = await response.json();

  console.log(users);
}
```

Query Parameter를 사용할 때:

```javascript
async function searchBooks(query) {
  const encodedQuery = encodeURIComponent(query);
  const response = await fetch(`https://api.example.com/books?query=${encodedQuery}`);
  const data = await response.json();

  console.log(data);
}
```

실무에서는 검색어에 특수 문자가 들어갈 수 있으므로 `encodeURIComponent`를 사용하는 것이 좋다.

```javascript
const query = encodeURIComponent("자바스크립트 기초");
const response = await fetch(`https://api.example.com/books?query=${query}`);
```

## 3. POST 요청
POST 요청은 데이터를 생성할 때 사용한다.

```javascript
async function createUser() {
  const response = await fetch("https://api.example.com/users", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      name: "Kim",
      email: "kim@example.com"
    })
  });

  const createdUser = await response.json();
  console.log(createdUser);
}
```

* `method`: 요청 방식
* `headers`: 요청에 대한 부가 정보
* `body`: 서버로 보낼 데이터
* `JSON.stringify`: JavaScript 객체를 JSON 문자열로 변환

## 4. 인증 헤더 포함 요청
인증이 필요한 API는 토큰을 헤더에 포함한다.

```javascript
async function getMyProfile() {
  const response = await fetch("https://api.example.com/me", {
    headers: {
      Authorization: "Bearer access_token"
    }
  });

  const profile = await response.json();
  console.log(profile);
}
```

## 5. JSON 응답 처리
API 응답이 JSON이면 `response.json()`으로 JavaScript 객체로 변환할 수 있다.

응답 예시:

```json
{
  "id": 1,
  "name": "Kim",
  "profile": {
    "email": "kim@example.com"
  },
  "roles": ["admin", "user"]
}
```

값 꺼내기:

```javascript
console.log(data.id);
console.log(data.name);
console.log(data.profile.email);
console.log(data.roles[0]);
```

배열 응답 처리:

```javascript
const users = [
  { "id": 1, "name": "Kim" },
  { "id": 2, "name": "Lee" }
];

users.forEach((user) => {
  console.log(user.name);
});
```

## 6. 화면에 데이터 표시하기
```html
<ul id="user-list"></ul>
```

```javascript
async function renderUsers() {
  const response = await fetch("https://api.example.com/users");
  const users = await response.json();
  const userList = document.querySelector("#user-list");

  userList.textContent = "";

  users.forEach((user) => {
    const item = document.createElement("li");
    item.textContent = user.name;
    userList.appendChild(item);
  });
}
```

API 응답 데이터를 HTML로 변환해 화면 일부만 갱신할 수 있다. 이것이 AJAX가 웹 페이지 전체 새로고침 없이 동작하는 기본 방식이다.
