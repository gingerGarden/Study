## 1. 문서 목적
이 폴더의 문서는 API를 처음 접하는 단계에서 시작해, 실무에서 API를 설계하고 사용하는 데 필요한 핵심 개념까지 순서대로 익히기 위한 학습 자료이다.

문서만 읽는 것으로 실무 전문가가 되는 것은 어렵지만, 이 자료를 바탕으로 실습을 병행하면 API 설계, 호출, 문서화, 보안, 운영에 대한 기본 판단력을 만들 수 있다.

## 4. 실습 권장 순서
문서를 읽은 뒤 다음 순서로 직접 만들어보면 이해가 빨라진다.

1. `fetch`로 공개 API를 호출해 JSON 출력하기
2. 검색어를 Query Parameter로 전달하기
3. `POST` 요청으로 JSON Body 전송하기
4. Express로 `/users` API 만들기
5. 상태 코드와 표준 에러 응답 적용하기
6. OpenAPI 문서 작성하기
7. `curl` 또는 Postman으로 테스트하기

## 5. 최종 점검 질문
아래 질문에 답할 수 있으면 API 기초와 실무 핵심 개념은 어느 정도 숙지한 것이다.

* `GET`, `POST`, `PUT`, `PATCH`, `DELETE`를 언제 사용하는가?
* Query Parameter와 Path Parameter의 차이는 무엇인가?
* `401`과 `403`은 어떻게 다른가?
* API Key, Bearer Token, OAuth는 어떤 상황에서 사용하는가?
* REST API에서 URI에 동사를 넣지 않는 이유는 무엇인가?
* `fetch`에서 `response.ok`를 확인해야 하는 이유는 무엇인가?
* CORS 오류는 왜 프론트엔드 코드만으로 해결하기 어려운가?
* Breaking Change를 피하려면 어떤 방식으로 API를 변경해야 하는가?
* API 장애를 추적하려면 어떤 로그와 지표가 필요한가?
