## 1. 기본 용어
| 용어 | 의미 |
|----|----|
| API | 프로그램 사이에 기능이나 데이터를 주고받기 위한 규칙과 접점 |
| Client | API를 호출하는 쪽 |
| Server | API 요청을 처리하고 응답하는 쪽 |
| Endpoint | 특정 기능이나 자원에 접근하기 위한 URL |
| Resource | API에서 다루는 대상. 예: 사용자, 게시글, 주문 |
| URI | 자원을 식별하는 주소 |
| HTTP Method | 요청의 행위를 나타내는 방식. 예: `GET`, `POST`, `PATCH` |

<br>

## 2. 요청 관련 용어
| 용어 | 의미 |
|----|----|
| Header | 요청이나 응답의 부가 정보 |
| Body | 서버로 보내는 실제 데이터 |
| Query Parameter | URL 뒤에 붙는 검색 조건 |
| Path Parameter | URL 경로에 포함되는 식별 값 |
| Content-Type | 요청 또는 응답 본문의 데이터 형식 |
| Authorization | 인증 정보를 담는 헤더 |

<br>

## 3. 응답 관련 용어
| 용어 | 의미 |
|----|----|
| Status Code | 요청 처리 결과를 나타내는 HTTP 상태 코드 |
| JSON | API에서 자주 사용하는 데이터 형식 |
| Error Code | 서비스가 정의한 구체적인 오류 코드 |
| Pagination | 목록 데이터를 여러 페이지로 나누어 제공하는 방식 |
| Cursor | 다음 목록 조회 위치를 나타내는 값 |

<br>

## 4. 보안 관련 용어
| 용어 | 의미 |
|----|----|
| Authentication | 사용자가 누구인지 확인하는 인증 |
| Authorization | 사용자가 어떤 작업을 할 수 있는지 확인하는 인가 |
| API Key | API 사용자를 식별하기 위해 발급하는 키 |
| Bearer Token | 인증 후 API 접근에 사용하는 토큰 |
| JWT | JSON 정보를 서명된 토큰으로 표현하는 방식 |
| OAuth | 외부 서비스 권한을 위임받기 위한 표준 |
| CSRF | 로그인 상태를 악용해 원하지 않는 요청을 보내게 하는 공격 |
| XSS | 웹 페이지에 악성 스크립트를 삽입하는 공격 |

<br>

## 5. 운영 관련 용어
| 용어 | 의미 |
|----|----|
| Rate Limiting | 일정 시간 동안 허용할 요청 수를 제한하는 방식 |
| Timeout | 정해진 시간 안에 응답이 없으면 실패 처리하는 기준 |
| Retry | 실패한 요청을 다시 시도하는 전략 |
| Circuit Breaker | 외부 장애가 전체 장애로 번지는 것을 막는 패턴 |
| Monitoring | API 상태를 지표로 관찰하는 활동 |
| Logging | 요청과 처리 결과를 기록하는 활동 |
| OpenAPI | REST API를 표준 형식으로 설명하는 명세 |
| Swagger | OpenAPI 문서를 작성, 표시, 테스트하는 도구 생태계 |
